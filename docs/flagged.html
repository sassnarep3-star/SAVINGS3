How to use this page

If you can confirm any blank value on the official page (30 seconds with your ZIP), that confirmation is yours as of today — rates may have changed since Oct 22, 2026. To get this site updated, note the item ID (e.g., F-03), the value, the page’s “as of” date and your ZIP/state, and open an issue or PR against the repository; the fix goes in docs/research-notes.md first, then the table. Nothing on this page blocks the verified recommendations: every ranked number on the site is backed by a dated official source.
